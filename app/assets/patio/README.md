# Patio algérois approuvé

Décor généré pour WilayaDZ le 12 septembre 2026 à partir de la maquette
« proposition-architecture-v4-finitions », approuvée par le propriétaire.
Une seconde passe retire les textes du paysage et les commandes figées.
Les ressources WebP sont des découpes optimisées de cette planche : architecture,
écusson, frise, médaillon, enduit et carte-livre. Les cinq pictogrammes proviennent
de la maquette approuvée. Aucun portrait utilisateur n’est inclus dans ces fichiers.

`build.py` intègre les images au HTML pour le fonctionnement hors ligne.
`patio.css` place les vrais éléments HTML sur le décor. Le profil, les compteurs,
les libellés, la langue et la progression ne sont jamais peints dans l’image.
Le logo illustré reste bilingue-indépendant et son bouton possède un nom accessible.

L’accueil garde sa palette ivoire et faïence dans les thèmes clair/sombre ;
les autres pages conservent le thème choisi. Les contenus pédagogiques et leurs
ressources restent disponibles ; la carte d’accueil emploie le livre de la maquette.
